## 🆘 Troubleshooting

### Sidebar not opening?
- **Clear cache** (Ctrl+Shift+Delete)
- **Refresh page** (pull down to refresh)
- **Try different browser**

### Layout looks weird?
- **Wait for deployment** (2-3 minutes)
- **Hard refresh** (Ctrl+Shift+R or Cmd+Shift+R)
- **Clear browser cache**

### Buttons too small?
- **Zoom out** if you zoomed in
- **Check deployment** is complete
- **Try landscape mode**

### Text too small?
- **Increase browser font size** in settings
- **Use landscape mode** for more space
- **Zoom in** if needed

## 📱 Best Practices for Mobile Use
